## 📂 Highlighted Projects (주요 프로젝트)

### 🗂 1. WorkB — AI 기반 회의 어시스턴트 플랫폼
- **설명:** 회의 아젠다 자동 생성, 실시간 회의록 요약, 태스크 분배 자동화를 수행하는 지능형 플랫폼
- **핵심 기술:** `LangChain`, `LangGraph`, `Multi-Agent System`, `FastAPI`
- **담당 역할:** 멀티에이전트 시스템 아키텍처 설계 및 구현 주도, LLM API 및 오케스트레이션 최적화

### 🎨 2. Oneness — 아동 미술 심리 및 다이어리 분석 서비스
- **설명:** 아이들의 그림과 일기를 분석하여 심리적 인사이트와 객관적인 리포트를 제공하는 서비스
- **핵심 기술:** `OCR`, `Object Detection (YOLO/CNN)`, `OpenCV`
- **담당 역할:** 필기체 인식 손글씨 OCR 파이프라인 구축 및 그림 내 심리 분석용 오브젝트 탐지 모델 최적화

### 🐻 3. HotelBear — 호텔 가격 예측 및 가성비 분석 모델
- **설명:** 야놀자 등 주요 숙박 플랫폼 데이터를 크롤링하여 실시간 가격 트렌드를 예측하고 분석하는 시스템
- **핵심 기술:** `XGBoost`, `LightGBM`, `Web Scraping`, `Pandas`
- **담당 역할:** 숙박 데이터 수집 크롤러 개발, 대용량 데이터 전처리 및 머신러닝 예측 모델링
